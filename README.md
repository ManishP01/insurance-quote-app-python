# PolicyPal - Multilingual AI Insurance Assistant

A professional insurance platform with AI-powered multilingual support.

## Features
- Smart OpenAI-powered chatbot
- Multilingual support (English, Hindi, Spanish)
- Document analysis with Vision API
- Professional Travelers-style UI
- SSL bypass for corporate networks

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Set up environment: Copy `.env.example` to `.env` and add your OpenAI API key
3. Run: `python3 app.py`
4. Open: http://localhost:5000

## Environment Variables
- `OPENAI_API_KEY`: Your OpenAI API key
- `DISABLE_SSL_VERIFY`: Set to 'true' for corporate networks
